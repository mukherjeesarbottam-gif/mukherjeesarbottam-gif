## 🏆 FEATURED PROJECTS

### 🛡️ ANVEX — AI-Powered Cyber Threat Detection

* **Role:** AI/ML & Threat Engine Lead
* **Problem:** Modern network threats require rapid, automated detection mechanisms that static rule-based security filters miss.
* **Contribution:** Engineered the core AI/ML threat-detection layer focusing on network traffic analysis and explainable ML. Implemented a 13-feature network representation using an XGBoost multiclass classifier and Isolation Forest anomaly detector. Built heuristic engines for DDoS, Port Scans, DGA, C2 Beacons, and Exfiltration leveraging Zeek logs, SHAP explainability, and dynamic alert severity scoring.

### 📩 MAILSHIELD — Intelligent Email Spam Detection

* **Role:** AI/ML & NLP Engineer
* **Problem:** Phishing and malicious emails utilize dynamic, evolving language patterns that bypass conventional rule filters.
* **Contribution:** Architected the end-to-end spam detection pipeline and NLP feature extractor. Built an optimized text preprocessing system combining TF-IDF vectorization, embedded URL threat indicators, and LinearSVC classification models. Deployed a FastAPI microservice backend linked to a responsive React/TypeScript user application.
